# 🚀 Workshop TDC: Modernize seu Monólito .NET

Bem-vindo ao workshop de modernização de aplicações .NET! Neste workshop de 90-120 minutos, você aprenderá como transformar uma aplicação legada do [.NET Framework](https://docs.microsoft.com/pt-br/dotnet/framework/) em uma aplicação moderna utilizando [.NET](https://docs.microsoft.com/pt-br/dotnet/) com ferramentas de IA e [GitHub Copilot](https://docs.github.com/pt/copilot).

## 📋 O que você vai aprender

Ao final deste workshop, você terá adquirido:

⬆️ Experiência prática na atualização para .NET moderno  
🤖 Conhecimento sobre modernização de código com GitHub Copilot  
🧠 Habilidades para integrar capacidades de IA em suas aplicações  

## 🎯 Pré-requisitos

Você deve estar familiarizado com [C#](https://docs.microsoft.com/pt-br/dotnet/csharp/) e .NET - o suficiente para se sentir confortável com APIs web e aplicações [Blazor](https://docs.microsoft.com/pt-br/aspnet/core/blazor/). Cobriremos o uso do GitHub Copilot ao longo do caminho - mas não se preocupe, você não precisa ser um especialista.

Aqui estão algumas coisas que você vai precisar:

🔨 [Visual Studio 2022](https://visualstudio.microsoft.com/pt-br/vs/) ou superior  
🤖 Acesso a uma assinatura do GitHub Copilot Pro  
💾 [.NET 9 SDK](https://dotnet.microsoft.com/pt-br/download/dotnet/9.0)  
🗄️ [SQL Express](https://www.microsoft.com/pt-br/download/details.aspx?id=104781) (para desenvolvimento local)

## 📚 Estrutura do Workshop

Este workshop está dividido em módulos progressivos, cada um construindo sobre o anterior:

### 🎤 [Introdução](./00-introducao.md) (10-15 minutos)
Apresentação do tema, contexto do monólito a ser modernizado e visão geral do workshop.

### 🔧 [1. Configurando o Ambiente](./01-configurando-ambiente.md) (15-20 minutos)
Preparação do ambiente de desenvolvimento com todas as ferramentas necessárias para o workshop.

### 🔄 [2. Atualização do .NET](./02-atualizacao-dotnet.md) (20-25 minutos)
Processo de migração de aplicações .NET Framework para .NET moderno usando ferramentas assistidas por IA.

### 🤖 [3. Modernização com Copilot](./03-modernizacao-copilot.md) (30-40 minutos)
Refatoração e modernização da arquitetura usando GitHub Copilot para aplicar melhores práticas.

### 🧠 [4. Incorporando IA](./04-incorporando-ia.md) (20-25 minutos)
Adição de capacidades inteligentes à aplicação usando GitHub Models e Azure.AI.Inference.

### 🎓 [Considerações Finais](./05-consideracoes-finais.md) (5 minutos)
Recapitulação, próximos passos e recursos adicionais para continuar sua jornada de modernização.

## ⏱️ Duração Total

**90 a 120 minutos** de conteúdo prático e teórico.

## 🚀 Como Começar

1. Clone este repositório
2. Siga a seção [Configurando o Ambiente](./01-configurando-ambiente.md) para preparar seu ambiente
3. Avance pelos módulos na ordem apresentada
4. Pratique os exercícios em cada seção

## 💡 Dicas para o Workshop

- 📝 Mantenha o Visual Studio aberto durante todo o workshop
- 🤔 Não hesite em fazer perguntas durante as sessões práticas
- 💻 Tente completar os exercícios antes de ver as soluções
- 🔄 Se ficar travado em algum ponto, peça ajuda ao instrutor
